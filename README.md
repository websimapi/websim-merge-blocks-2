# 🎮 Merge Blocks - Interactive Puzzle Game

A dynamic web-based puzzle game where you merge and split numbered blocks on a grid with physics-based spawning mechanics!

## ✨ Key Features

- **4 Difficulty Modes**: Easy, Medium, Hard, and Zen
- **Dual Mechanics**: Merge identical blocks OR split different blocks to their average
- **Physics Hourglass**: Real sand physics determines spawn timing
- **Custom Themes**: Generate AI images for any theme you want
- **Smart Indicators**: See where blocks will spawn next
- **Drag & Drop**: Intuitive touch and mouse controls

## 🎯 How to Play

1. **Merge**: Drag identical numbers together → they combine into next level
2. **Split**: Drag different numbers together → both become their average (if even)
3. **Survive**: Keep making moves as the hourglass runs out
4. **Score**: Higher level blocks = more points

## 🛠️ Tech Stack

- **Vanilla JavaScript** (ES6 modules)
- **Matter.js** - Physics simulation for hourglass
- **Canvas API** - Rendering
- **CSS Grid** - Responsive layout
- **AI Image Generation** - Custom themes

## 🎲 Game Modes

- **Easy/Zen**: Click spawn indicators, see all merge hints
- **Medium**: No merge hints, random spawns
- **Hard**: No hints, no merge UI, faster pace

Try different themes like "cats", "food", "space" - watch your blocks transform into themed images!
